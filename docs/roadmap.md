# Roadmap

## Phase 1 — MVP (COMPLETE)

- Smart contract: escrow, milestones, disputes, 3% fee ✅
- API: wallet management, escrow service, KYC flow ✅
- Frontend: web dashboard, landing page ✅
- Mobile: React Native app, APK + Expo Go ✅
- Deployed to Stellar testnet ✅
- Live demo: [escrowflowhq.com](https://www.escrowflowhq.com) ✅

## Phase 2 — Production Ready (Q4 2026, 6 months)

- Real KYC integration (Stripe Identity or Onfido)
- Off-ramp corridors: bank transfer (Wise), mobile money (Flutterwave), crypto (USDC bridges)
- Smart contract security audit
- Dispute resolution UI (web + mobile)
- Webhooks & real-time notifications
- Beta testers in 3 geographies: Lagos, Manila, Nairobi
- Community feedback & iteration

## Phase 3 — Scale & Mainnet (Q2 2027, 6 months)

- Mainnet deployment (Stellar production network)
- iOS App Store + Google Play release
- Agency accounts (teams, multi-user)
- Dispute arbitration team (human moderators)
- Marketing & user acquisition
